# NighTime Bikes
Pagina de venta de bicicletas y accesorios; includio sistema de gestion de inventario y personal

# Lenguajes usados 
    - python (Django)
    - MySql (base de datos)
    - HTML+CSS (Front End)

# Instalacion del proyecto 
    1. Clonar el repositorio: `git clone ...`
    2. Crear el entorno virtual: `python -m venv venv`
    3. Activar el entorno: `.\venv\Scripts\Activate.ps1`
    4. Instalar dependencias: `pip install -r requirements.txt`
    5. Ejecutar migraciones: `python manage.py migrate`
    6. Iniciar el servidor: `python manage.py runserver`
